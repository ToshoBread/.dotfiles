---
description: Save certain contexts in a markdown file
---

Write a markdown file in context/ (Create the directory if doesn't exist yet)

File name: context-<CURRENT DATE>-<SHORT TITLE>.md

Format:

```markdown
# Short Title

## Purpose

Content
```

The content is about $ARGUMENTS.

Write it as if another agent will read it; so make it minimally ambiguous and token efficient yet still capturing the core idea of the subject.
